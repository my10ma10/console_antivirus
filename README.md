# Приложение для проверки файлов на "вредоносные" паттерны

## Описание

Приложение состоит из нескольких утилит:
- Клиент для отправки файлов на проверку
- Сервер для проверки файлов на наличие вредоносных паттернов
- Утилита для вывода статистики 

Приложение работает на Linux, покрыто юнит-тестами. 

## Системные требования 

Для сборки требуется:
- компилятор для C++17 и выше
- CMake версии 3.14 и выше
- 

## Сборка 
```bash
cmake -S . -B build
cmake --build build
```

## Запуск

### Сервер
В аргументы серверу необходимо передать путь до конфигурационного
файла и номер порта.

Пример запуска:
```
    ./build/src/server/server config_files/config.json "8080"
```

При ошибке в консоль будет выведено описание ошибки.

### Клиент
В аргументы клиенту необходимо передать путь до файла, который
необходимо проверить, и номер порта. 

Пример запуска:
```
    ./build/src/client/client "/my_file.txt" "8080"
```
Пользователю в консоль будет выведено одно из двух сообщений: `The file has been verified` или `The file has not been verified and is considered malicious`. При ошибке будет выведено описание ошибки.

## Утилита для отображения статистики

Запуск утилиты:
```
    ./build/src/stats_util/stats_util
```

Пользователю в консоль будет выведена полученная от сервера статистика. Пример выведенной статистики:  
```
Stats: 
Number of files checked: 10
Number of malware patterns: 3
Patterns: 
        DROP TABLE SomeTable: 1 time
        rm -rf: 2 times
```
